================================================================================
INSTALLATION & SETUP
================================================================================

1. Install dependencies:
   npm install puppeteer zod

2. Add Prisma schemas from PRISMA_SCHEMA_ADDITIONS.md

3. Run migration:
   npx prisma migrate dev --name add_api_modules
   npx prisma generate

4. Configure environment variables:
   DATABASE_URL, JWT_SECRET, ANTHROPIC_API_KEY, DEEPSEEK_API_KEY, OPENAI_API_KEY

5. Start server:
   npm run dev

6. API available at: http://localhost:4000
